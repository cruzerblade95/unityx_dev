# Admin NOWPayments Controller - XEUSD Integration Fix

## Issues Fixed

### Issue 1: XEUSD Deposits Showing as "NOWPayments"
**Problem:** XEUSD deposits (payment_method='xeusd') were displaying as "NOWPayments" in the admin deposit list.

**Solution:** Updated the `payment_id` column rendering to detect XEUSD deposits first and display them with a green "XEUSD" badge.

### Issue 2: 500 Error When Approving XEUSD Deposits
**Problem:**
- Clicking "Approve" on XEUSD deposits caused a 500 Internal Server Error
- Console error: "Unexpected token '<', "<!DOCTYPE "... is not valid JSON"
- Root cause: Code was trying to query NOWPayments API for XEUSD deposits

**Solution:** Updated approval logic to skip NOWPayments API call for XEUSD deposits and use the already-verified amount.

## Changes Made

### File: `app/Http/Controllers/Admin/NOWPaymentsController.php`

#### Change 1: Payment Method Display

**Before:**
```php
->addColumn('payment_id', function ($deposit) {
    if ($deposit->payment_method === 'manual') {
        return '<span class="badge bg-secondary">Manual</span>';
    }
    if ($deposit->payment_method === 'nowpayments' || $deposit->payment_id) {
        // XEUSD was falling into this condition
        return '<code>...' . $deposit->payment_id . '</code><br>NOWPayments';
    }
    ...
})
```

**After:**
```php
->addColumn('payment_id', function ($deposit) {
    // Check for XEUSD payment method FIRST
    if ($deposit->payment_method === 'xeusd') {
        if ($deposit->payment_id) {
            $shortTxHash = substr($deposit->payment_id, 0, 10) . '...' . substr($deposit->payment_id, -8);
            return '<a href="https://bscscan.com/tx/' . $deposit->payment_id . '" target="_blank">' .
                   '<code>' . $shortTxHash . '</code></a>' .
                   '<br><span class="badge bg-success">XEUSD</span>';
        }
        return '<span class="badge bg-success">XEUSD</span>';
    }

    if ($deposit->payment_method === 'manual') {
        return '<span class="badge bg-secondary">Manual</span>';
    }

    // Now check for NOWPayments/crypto
    if ($deposit->payment_method === 'nowpayments' || $deposit->payment_method === 'crypto') {
        return '<code>...' . $deposit->payment_id . '</code><br>NOWPayments';
    }
    ...
})
```

#### Change 2: Approval Logic

**Before:**
```php
public function approveDeposit($depositId)
{
    // For ALL deposits with payment_id, query NOWPayments
    if ($deposit->payment_id) {
        $nowpaymentsData = $this->nowPayments->getPaymentStatus($deposit->payment_id);
        // This caused 500 error for XEUSD deposits
    }
    ...
}
```

**After:**
```php
public function approveDeposit($depositId)
{
    // Only query NOWPayments for NOWPayments/crypto deposits
    if (($deposit->payment_method === 'nowpayments' || $deposit->payment_method === 'crypto') && $deposit->payment_id) {
        $nowpaymentsData = $this->nowPayments->getPaymentStatus($deposit->payment_id);
        ...
    }

    // For XEUSD deposits, use the amount (already verified on blockchain)
    if ($deposit->payment_method === 'xeusd') {
        $creditAmount = $deposit->amount; // XEUSD has no fees
    }
    ...
}
```

#### Change 3: Actions Column

**Before:**
```php
// Showed "Refresh" button for ALL deposits with payment_id
if ($deposit->payment_id) {
    $actions .= '<button onclick="refreshPaymentStatus(...)">Refresh</button>';
}

// Only allowed Reject for manual deposits
if ($deposit->payment_method === 'manual' || !$deposit->payment_id) {
    $actions .= '<button onclick="showRejectModal(...)">Reject</button>';
}
```

**After:**
```php
// Only show "Refresh" for NOWPayments/crypto (not XEUSD)
if ($deposit->payment_id && $deposit->payment_method !== 'xeusd') {
    $actions .= '<button onclick="refreshPaymentStatus(...)">Refresh</button>';
}

// Allow Reject for manual, XEUSD, and deposits without payment_id
if ($deposit->payment_method === 'manual' || $deposit->payment_method === 'xeusd' || !$deposit->payment_id) {
    $actions .= '<button onclick="showRejectModal(...)">Reject</button>';
}
```

## Error Handling

### Original Error:
```
POST /admin/deposits/approve/18 500 (Internal Server Error)
Error: SyntaxError: Unexpected token '<', "<!DOCTYPE "... is not valid JSON
```

**Root Cause:**
- NOWPayments API was being called with XEUSD transaction hash
- API returned HTML error page (not JSON)
- JavaScript tried to parse HTML as JSON → Error

**Fix:**
- Skip NOWPayments API call for XEUSD deposits
- Use pre-verified amount from blockchain verification
- Return proper JSON response
